# 投递管理 V1.2 / beta.8 验收记录

基线：beta.7（8e96df3）。本轮按 V1.2 开发，并纳入后续追加要求：主时间改为当前阶段截止时间、数据列接近等宽、进度表头与点状进度居中。

## 已完成

- 顶部控制区 HTML 与基线逐字比较一致；新增样式仅作用于投递内容区和相关弹窗。
- 卡片：公司 Logo / 文字 fallback、岗位标题、有效辅助信息、当前阶段截止时间、最多三个标签及 +N、岗位链接、投递总结、阶段操作；删除收进更多菜单。
- 表格：公司与岗位、城市、岗位类型、标签、当前阶段、点状进度、当前阶段截止时间、精简操作；支持选择及批量被拒绝、已放弃、恢复。
- 各阶段可被拒绝 / 已放弃；Offer 可标记 Offer 已拒绝；结束记录排序沉底、Logo 和历史进度弱化、保留编辑和完整历史。支持恢复进行中。
- 编辑窗口和卡片移除简历界面；保留旧数据中的简历字段，避免编辑其他信息时丢失原始数据。
- 截止时间按 workflow.deadlines 的阶段 ID 独立保存，切换阶段自动显示；支持直接输入、日期时间选择、清除及保存前预览。支持 72小时内、3天内、90分钟内、明天下午5点、明确日期时间；相对时间在编辑窗口打开时固定起算，保存后不漂移。
- 修改其他信息时保留原有阶段时间和投递时间；编辑器阶段 ID 归一化时同步映射各阶段截止时间。
- Company 实体共享，规范化名称去重；companySchemaVersion=1 增量迁移，保留主工作区 version=11 及旧岗位字段。迁移前生成可恢复备份。
- Logo 在主进程异步获取：手动图片、本地缓存、招聘页结构化雇主 Logo / 官网、官网标识、favicon、文字 fallback；不会把招聘平台 favicon 当作雇主 Logo。未知官网可在更多菜单中设置。
- Logo 30 天缓存、失败保留旧图、并发限制、局部刷新；最终 PNG 最大 512px，随附件目录迁移。没有匹配图片的公司仍显示文字 fallback。
- 网络获取限制 HTTP(S)、公开 IP、DNS 绑定、重定向上限 3、请求总超时 10 秒、连接超时 5 秒、5MB 上限；校验内容类型、文件头和真实解码。
- 旧的日期型即写即走任务在实际读取数据时修复跨日显示，保留原 ID、关联和扩展字段，并先备份。
